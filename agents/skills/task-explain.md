# Task Explain

Explique uma tarefa de programação que já foi finalizada.

Use este formato:

## Código

Mostre os principais trechos de código alterados.

## O que foi feito

Explique de forma simples o que foi criado, alterado ou corrigido.

## Por que foi feito desse jeito

Explique de forma simples por que essa solução foi usada.

## Regras

* Explique como se estivesse falando com uma pessoa iniciante em programação.
* Use palavras simples e frases diretas.
* Evite termos técnicos desnecessários.
* Quando usar um termo técnico, explique o que ele significa.
* Não invente informações.
